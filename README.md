# 🎨 Artist Portfolio & Fine Art Store

Welcome to the official repository for my Art Portfolio & Online Store! This website showcases original acrylic paintings, high-detail graphite/pencil sketches, and offers custom commission bookings and art prints.

---

## ✨ Features

- 🖼️ **Interactive Artwork Gallery:** Categorized grid for Original Paintings, Pencil Sketches, and Prints.
- 🔍 **Full-Screen Lightbox View:** View artwork details, dimensions, and medium high-resolution previews.
- 📩 **Custom Commission Request Form:** Easy inquiry form for personalized artwork requests.
- 📱 **Fully Responsive Design:** Optimized for seamless viewing on mobile, tablet, and desktop devices.
- 📹 **Social & Reels Showcase:** Integrated video previews highlighting the art creation process.
